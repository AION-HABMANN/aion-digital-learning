# Task 1 · Route 1 · UX Analysis File (Levels 1 and 2)

## The case: LearnBase, a feature-heavy platform without user focus

LearnBase is a learning platform with many functions and low usage. Learners cannot find the content they need and are frustrated. A first analysis points to system logic instead of user logic, and to no clear user guidance. Management wants growth, satisfaction is falling, and the budget is limited. You are the UX lead and must say what to do.

| What you have | The limits | How the task runs |
|---|---|---|
| Four LearnBase screens in outline and eight facts about them (Block 1.1).<br>Three options for the platform (optional Block 1.2) and seven possible user problems (optional Block 2.1).<br>Nine measures, each with a cost and weeks (Block 2.2). | **Budget:** €40,000 (Case assumption: the plan only says "limited")<br>**Time:** 3 months (13 weeks, Case assumption)<br>Satisfaction is declining; management demands growth. | Two Core blocks, about 30 minutes:<br>1. Block 1.1: take the learner's position, sort eight facts, write three expectations.<br>2. Block 2.2: choose four of nine measures, rate them, order them.<br>Three more blocks (about 20 minutes) are Optional. |

:::note Case assumption
The brief says: many functions but low usage, learners cannot find content, high frustration, system logic instead of user logic, no clear user guidance, unclear navigation, a limited budget, falling satisfaction, and management demanding growth. Everything else is made up for this exercise: the screens, the numbers on them, the €40,000, the 13 weeks, and the costs and weeks of the measures.
:::
