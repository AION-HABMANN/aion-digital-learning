# Task 1 · Route 1 · UX Analysis File (Levels 1 and 2)

## The case: MobileLearn, a platform with poor mobile usage

MobileLearn is a learning platform that was optimised for the desktop. Mobile use is rising sharply, and the drop-out rate on smartphones is high. A first analysis points to content that is too long and to no adaptation for the phone. The content is complex and the budget is limited. You are part of the UX team and asked to work out what goes wrong for a learner on the move, and which measures are worth funding.
