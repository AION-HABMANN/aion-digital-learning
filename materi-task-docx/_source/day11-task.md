# Task 1 · Route 1 · UX Analysis File (Levels 1 and 2)

## The case: GameLearn, a platform with high activity and low learning

GameLearn is a learning platform full of game elements. Users collect points, but they learn little, and the focus has shifted from the content to the reward. A first analysis points to a wrong gamification strategy, in which extrinsic motivation dominates. Users drop out early, the content is complex and the budget is limited. You are part of the UX team and asked to work out which elements help, which only reward activity, and which measures are worth funding.
